# Instalar el acceso por usuario (Cima Blanca)
Orden: 1) Apps Script ACCESO desplegado (ver archivo .gs). 2) Subir el ZIP.
1. Descomprime el ZIP.
2. En GitHub (repo dashboard_financiero) sube TODO el contenido respetando carpetas: index.html, auth.js, manifest.webmanifest, sw.js, icons/, y la carpeta de cada módulo (actividad, adicionales, cancelaciones, dashboard, directas, gastos, ingresos, parametros, sincronizar). Reemplaza los existentes.
3. Espera el despliegue de Vercel (1 min) y abre la app. Debe pedir usuario y clave.
4. Celular: abrir en Safari (iPhone/iPad) o Chrome (Android) > Compartir > Añadir a pantalla de inicio.
